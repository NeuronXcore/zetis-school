Notes de maquette — ce que la composition applique
  • Une seule action accentuée : « Commencer ». « Discuter avec ZETIS » est volontairement en bouton fantôme — c'est une invitation, pas le chemin guidé du jour.
  • Aucun or. #ffcf47 reste réservé à l'état « ZETIS parle » ; l'onde du héros est en état idle, donc cyan/indigo.
  • Ma semaine : jeudi (à venir) et un jour passé sans activité seraient rendus à l'identique. Aucun compteur de manque, aucun pourcentage, aucune série.
  • Révision éclair · 5 — c'est flash_size, jamais total_due. Le « 23 à revoir » de la référence est un compteur de retard, interdit sur l'Accueil.
  • Carte Galaxie : un compte d'étoiles allumées, quatre pastilles de matières en CSS pur. Zéro import de @zetis/ui/galaxy/canvas — le chunk 1,37 Mo ne doit plus entrer sur la page d'atterrissage (addendum §B).
  • Message ZETIS rendu verbatim depuis /api/student/motivation/welcome. Aucune phrase de secours, aucun bandeau motivationnel fabriqué côté client.
  • Le héros ZETIS est un slot : sa place est structurée par la slice B, mais le bloc n'est pas rendu tant que le chat (ADR-0026) n'existe pas. Le Groupe 1 le remplira sans rouvrir la composition de la page.
  • Sidebar : chrome global (MassimoLayout), hors périmètre du chantier. Seul changement : « Progression » → « Ma Galaxie », même position, pas de 6ᵉ onglet.
  • Divergence à trancher hors chantier : « Diagnostic » figure dans la sidebar du README frontend-massimo alors que navigation.md §9 dit qu'il n'est pas un item de menu pour Massimo mais une mission spéciale. Rendu ici tel que le README le décrit ; à vérifier contre le code au read-before-code.
  • La grille des 8 matières de la référence a disparu : doublon de l'entrée « Matières », et la carte Galaxie répond mieux à « où j'en suis ».
