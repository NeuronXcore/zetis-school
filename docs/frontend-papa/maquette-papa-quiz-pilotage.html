Q1 · QCM · notion : accord avec être
Avec l'auxiliaire être, le participe passé s'accorde avec…
le complément d'objet direct
le sujet ✓ CLÉ
le verbe conjugué
rien — il est invariable
Explication servie à Massimo : Avec être, le participe suit le sujet comme un adjectif : « elles sont parties ». Le COD, lui, ne compte que pour l'auxiliaire avoir.

Enregistrer passe cette question en Manuel : elle survivra aux régénérations ↻.

Coche toutes les phrases correctement accordées :
