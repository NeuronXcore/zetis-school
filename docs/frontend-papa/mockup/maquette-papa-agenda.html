Notes de maquette — non normatives, reprises de l'ADR-0025
  • Aucune case à cocher sur cette page. L'état « fait » est une pastille en lecture seule. Si l'affordance existait, la coche deviendrait une validation parentale et l'objet basculerait du côté du contrôle.
  • L'écart déclaré / fait se lit, il n'alerte pas. Pas de rouge, pas de badge « en retard », pas de compteur d'arriéré. L'ADR interdit d'émettre un événement d'échec — l'UI ne doit pas le réintroduire par la couleur.
  • Éditer un item de Massimo prévient. Le panneau affiche explicitement que la correction portera la mention « complété par papa » dans son agenda. Pas de modification silencieuse.
  • La note parent n'est jamais servie à Massimo — schéma `AgendaItemPilotOut` séparé, testé côté serveur, et rappelé dans l'UI pour lever le doute.
  • Archiver, pas supprimer. Un item de Massimo n'est jamais effacé : il est masqué, récupérable, et reste visible sous le filtre « Archivés ».
  • Un item masqué par Massimo reste visible ici, atténué. Asymétrie assumée : le parent voit tout, l'enfant voit ce qui le concerne.
  • Barre de charge, pas de score. Le trait sous chaque jour indique le nombre d'échéances, jamais une performance.
