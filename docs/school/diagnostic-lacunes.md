# Diagnostic des lacunes

## Objectif

Identifier les notions qui empêchent Massimo de progresser dans le programme courant.

## Types

### Diagnostic global

Toutes matières ou grandes matières principales.

### Diagnostic matière

Une seule matière.

### Diagnostic prérequis

Teste les notions de 5e nécessaires à la 4e.

### Diagnostic flash

5 à 10 questions rapides avant une mission.

## Sorties attendues

- score par matière ;
- score par notion ;
- lacunes prioritaires ;
- confiance ;
- mission recommandée ;
- besoin d’ELI5 ;
- besoin de capsule.

## Formulation Massimo

Dire : “On cherche quoi renforcer.”

Ne pas dire : “On liste tes lacunes.”

## Formulation Papa

Papa peut voir le mot lacune, mais avec action proposée.
