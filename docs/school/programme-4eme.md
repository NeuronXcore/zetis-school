# Programme 4e — Stratégie ZETIS

## Important

Le programme scolaire officiel peut évoluer. ZETIS ne doit pas hardcoder définitivement le programme. Il doit permettre d’importer et valider des sources officielles, puis de structurer les notions.

## Matières à prévoir

- Français
- Mathématiques
- Histoire-Géographie
- EMC si ajouté plus tard
- SVT
- Physique-Chimie
- Technologie
- Anglais
- Espagnol

## Stratégie

Pour chaque matière :

1. importer programme ou progression ;
2. découper en chapitres ;
3. découper en notions ;
4. identifier prérequis de 5e ;
5. créer diagnostic ;
6. générer missions ;
7. planifier révisions.

## Exemple structure matière

```txt
Mathématiques 4e
├── Nombres et calculs
│   ├── nombres relatifs
│   ├── fractions
│   ├── puissances
│   └── calcul littéral
├── Géométrie
├── Grandeurs et mesures
└── Organisation et gestion de données
```

## Diagnostic N-1 / N

N-1 = acquis attendus de 5e.

N = notions de 4e.

Le diagnostic doit tester les prérequis puis les notions d’entrée en 4e.

## Réutilisation dans l’année

Le diagnostic doit être réutilisable plusieurs fois :

- rentrée ;
- fin de trimestre ;
- avant devoir important ;
- après une période difficile ;
- après consolidation.
