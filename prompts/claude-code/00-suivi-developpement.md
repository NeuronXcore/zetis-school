# Claude Code — Utiliser le suivi de développement

Lis `SUIVI_DEVELOPPEMENT_ZETIS.md` avant de modifier le projet.

Règles :

- travaille une seule étape à la fois ;
- respecte les critères de validation ;
- liste les fichiers créés et modifiés ;
- ne passe jamais à l’étape suivante sans validation humaine ;
- propose un commit Git à la fin de chaque bloc.

Commence par l’étape 1 : créer le squelette du projet.
